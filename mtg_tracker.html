📝 Setup Google Apps Script (One-time setup)

To sync with Google Sheets, you need to create a Google Apps Script deployment:

  1. Go to script.google.com
  2. Click "New project"
  3. Copy the code from mtg_tracker_apps_script.gs file in the repository
  4. Paste it into the script editor
  5. Click "Deploy" → "New deployment" → Type: "Web app"
  6. Set "Execute as" to your account
  7. Set "Who has access" to "Anyone"
  8. Click Deploy and copy the deployment URL
  9. Paste the URL in the field below
